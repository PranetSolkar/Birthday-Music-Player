# 🎵 Vinyl Birthday Music Player

An interactive vinyl-inspired music player built with **React, Vite, and Framer Motion** that combines a nostalgic record player with a personalized memory gallery.

The project was designed as a unique digital birthday experience featuring smooth shared-element animations, an animated gramophone, floating polaroid memories, theme switching, and a handcrafted UI.

## ✨ Features

- 🎶 Vinyl record based music collection
- 💿 Interactive Gramophone player
- 🎵 Play / Pause / Previous / Next controls
- 📀 Shared Element Transition using Framer Motion
- 🖼️ Animated Memory Gallery
- 📸 Draggable Floating Polaroids
- 🌙 Light / Dark Theme
- 🎂 Birthday Intro Animation
- 🎧 Music Progress & Volume Controls
- 📱 Fully Responsive (Desktop, Tablet & Mobile)
- ✨ Animated Background
- ⚡ Smooth Micro-interactions

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/PranetSolkar/Gramophone-Music-Player.git 
```

Move into the project

```bash
cd YOUR_REPOSITORY
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

## 🎨 Highlights

### Shared Element Animation

The selected vinyl record smoothly flies from the music collection into the gramophone using Framer Motion's `layoutId`.

---

### Interactive Gramophone

- Rotating vinyl
- Animated tonearm
- Audio synchronization
- Real-time playback controls

---

### Memory Gallery

The gallery includes:

- Animated birthday message
- Floating draggable polaroids
- Smooth entrance animations
- Responsive layout

---

### Theme Switching

Supports both:

- ☀️ Light Theme
- 🌙 Dark Theme

using CSS variables for seamless transitions.
